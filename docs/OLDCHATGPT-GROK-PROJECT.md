## What this Grok folder is

`OldCHATGPTNew…` on the Grok mobile Projects screen is **not a product**. There is no GitHub repo by that name. Treat it as an import/archive of older ChatGPT threads so they are not lost when work moved onto Grok.

Grok Project files are not readable from a chat started outside that folder. This note is the account-level handoff so the next assistant does not try to “ship” the archive.

## Salvage rules

Keep, then move into the matching product repo:

- Decisions, evidence labels, and product rules → `founder-os` (`PRODUCT-VISION.md`, `PROJECT-STATUS.md`)
- Arcade visual/runtime directives → `fish-shooter-arcade` (`CANONICAL_PROJECT_CHECKPOINT.md`)
- Map trust rules → `dumpsteratlas` (`docs/DATA-TRUST.md`)
- How-to editorial rules → `snarkyhowtos` (`README.md`, `content/youtube/`)
- Connector / multi-AI rules → this repo (`AGENTS.md`, `.ai/`)

Do not keep:

- Duplicate status reports that predate the GitHub source of truth
- Prompts that claim revenue, customers, or live shop URLs without a current health check
- Secrets, keys, passwords, personal IDs

## Recommended close-out

1. Open the Grok Project itself and export or copy any unique decisions not already in GitHub.
2. Paste those into the matching repo `HANDOFF` / `STATE` files.
3. Leave the Grok folder as read-only archive or delete it after the salvage pass.
4. Do not create a GitHub repo named OldCHATGPTNew.
