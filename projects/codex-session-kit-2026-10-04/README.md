# 40 Codex session briefs

40 distinct, actionable prompts spanning cash evidence, offers, media, story, publishing, analytics and operations. The first ten target the shortest honest path to a paid test. These are **prepared prompts**, not opened chats or finished jobs. No tool here can create 40 user-visible Codex chats. The offline dashboard copies prompts and saves local status; it does not run them or create accounts. Open `index.html`, launch a new chat manually, paste its prompt and attach/reconnect the workspace if needed. Follow dependencies rather than running conflicting repo edits at once.

The common $0 constraint refers to no new cash spend in the work plan; this environment cannot guarantee that the user's Codex subscription or usage is free. No prompt promises profit. Current project-state corrections, including Sparky exclusion and no verified $10,000 sale, are preserved in the relevant briefs.
