# Trend input contract

A phrase like “top 10 keywords on Google Trends” is incomplete without geography, time window, category, search type and whether “top” means trending searches or a comparison of known terms. Google Trends interest scores are normalized within a request and are not absolute search volume or sales demand. The local SmartPickShop Trend Lab is an evidence-entry scoring app; it does not furnish an automatic live keyword feed or a PDF in this workspace. As of October 4, 2026 Pacific, this session has no callable Google Trends research source, no Trend Lab PDF and no identified source stories. A network attempt to official platform pages earlier returned proxy 403. Therefore the sheet below is an **input**, with no fabricated top ten.

## Required snapshot

For each candidate: phrase, exact source URL or provided PDF page, checked date/time Pacific, geography (for example United States or San Jose area), 7-day/30-day/12-month time window, category, Web/YouTube/News/Image search type, rising/top classification, displayed index or position, related query context, evidence limitations, and any audience-safety concern. Save a raw export/screenshot if licensing and access permit. Do not scrape around access controls. A national trend may have no local audience connection.

`trends.csv` contains ten deliberately empty slots. Fill from one comparable snapshot or explicitly tag different snapshots; do not rank incomparable interest scores. `inspirations.csv` receives user-provided works and the specific high-level tension to transform, with a similarity warning and rights note. Neither file is evidence until filled and sourced.

## Selection score (editorial, 0–5 per factor)

- Character fit: can it create a fresh choice for a current character?
- Story payoff: can a complete local problem resolve on screen?
- Visuality: can action be shown with available locations and props?
- Evidence strength: is this a dated, attributable trend snapshot?
- Audience fit: does it serve the actual channel viewers, based on measured behavior?
- Production effort: lower effort receives higher score.
- Rights/safety: higher score means fewer unresolved permissions or harmful implications.

Record each 0–5 reason. A simple total is a discussion aid, not a prediction of virality, search traffic or profit. Demand, momentum, competition and monetization are separately assessed in Trend Lab only when evidence exists. Never upgrade an index value to customer demand. Pick one strong premise, leave nine in the queue and revisit after real retention and feedback.

Record geography, period, category, search type, whether the display says “trending,” “top,” or “rising,” checked time, page/URL and limitations. Compare only like-for-like snapshots. Do not add phrases from memory or call a normalized index search volume. Then read the attached SmartPickShop Trend Lab evidence and score each phrase for narrative fit, visual payoff, production effort and source strength. Return a table with ten rows, or fewer if the source has fewer. Mark unknown data unknown.
